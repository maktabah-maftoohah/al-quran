Dasar Privasi / Privacy Policy

Tarikh Kemas Kini Terakhir / Last Updated: 7 November 2026 • Maktabah Maftoohah Al-Quran

1. Pengenalan / Overview

Maktabah Maftoohah Al-Quran (https://maktabah-maftoohah.github.io/al-quran/) ialah aplikasi web Al-Quran sumber terbuka tanpa pelayan berpusat (client-side static web application). Kami menghormati sepenuhnya privasi anda dan komited untuk melindungi sebarang maklumat peribadi.

Maktabah Maftoohah Al-Quran is a free, open-source, client-side web application. We fully respect your privacy and are committed to protecting your personal information.

2. Data Yang Kami Kumpul & Simpan / Data We Collect & Store

Aplikasi ini beroperasi hampir sepenuhnya dalam pelayar web anda (browser-side only). Kami tidak mengendalikan pangkalan data pengguna pusat dan tidak mengumpul sebarang data identiti pengiklanan:

  • Data Tempatan (Local Storage): Penanda buku (bookmarks), nota tadabbur, sejarah bacaan, dan tetapan pilihan antara muka disimpan terus di storan peranti anda (Browser LocalStorage).
  • Penyegerakan Google Drive (Pilihan / Optional Cloud Sync): Sekiranya anda memilih untuk menyambungkan akaun Google anda, aplikasi menggunakan skop https://www.googleapis.com/auth/drive.appdata.

3. Penggunaan Skop Google Drive (drive.appdata) / Google Drive Scope Usage

Aplikasi Maktabah Maftoohah Al-Quran mematuhi Google API Services User Data Policy, termasuk keperluan Limited Use:

  • Ruang Storan Terhad (Sandbox Only): Skop drive.appdata hanya membenarkan aplikasi membaca dan menulis fail sandaran sendiri (maktabah-quran-sync.json) dalam ruang tersembunyi khusus aplikasi (Application Data Folder) pengguna.
  • Tiada Akses ke Fail Peribadi Lain: Aplikasi TIDAK MEMPUNYAI sebarang kebenaran untuk melihat, mengakses, mengedit, atau memadam fail peribadi, gambar, dokumen, atau folder lain dalam Google Drive anda.
  • Tiada Pemindahan Pihak Ketiga: Token akses Google dan fail sandaran tidak pernah dihantar, disalin, atau dijual kepada mana-mana pelayan pihak ketiga atau pihak pengiklan. Komunikasi berlaku terus antara pelayar web anda dan API rasmi Google.

4. Kawalan & Pembatalan Akses / Data Control & Access Revocation

Anda boleh memutuskan sambungan Google Drive pada bila-bila masa melalui menu Tetapan (Settings) → Putus Sambungan (Disconnect) dalam aplikasi. Anda juga boleh membatalkan kebenaran pada bila-bila masa melalui tetapan akaun Google anda di Google Account Permissions.

5. Hubungi Kami / Contact Us

Sekiranya anda mempunyai sebarang soalan mengenai dasar privasi ini, sila hubungi pentadbir kami melalui emel di naspenang@gmail.com atau buka isu di repositori GitHub Maktabah Maftoohah.
